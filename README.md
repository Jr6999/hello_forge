 hello_forge.dart

**Premier script Dart CLI - Sprint 01 | Programmation Mobile FORGE**

---

 Description

Ce projet contient mon **premier script en Dart** réalisé dans le cadre du Sprint 01.  
Il s’agit d’un programme console simple qui démontre la maîtrise des bases de Dart en ligne de commande.

---

Objectifs du Script

- Comprendre la structure d’un programme Dart (`void main()`)
- Gérer les arguments passés en ligne de commande
- Afficher des messages formatés
- Utiliser des variables simples (String, int, bool)

---

 Comment exécuter le script

### 1. Prérequis
- Flutter / Dart SDK installé et configuré
- Terminal (PowerShell, CMD ou Git Bash)

### 2. Exécution

# Se placer dans le dossier du projet
cd hello_forge

# Exécution simple
dart run
cd hello_forge

# Exécution simple
dart run
